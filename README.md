# Plataforma Web Gestión PGC

Sistema web orientado a la gestión, seguimiento y continuidad de los **Proyectos de Gestión del Conocimiento (PGC)**.

La plataforma busca centralizar la información de los proyectos, facilitar su seguimiento durante los ciclos académicos y permitir la consulta de proyectos anteriores para fomentar su continuidad y reutilización.

## Objetivo

Desarrollar una plataforma que permita gestionar el ciclo de vida de los PGC, desde la radicación y aprobación de propuestas hasta su desarrollo, evaluación y consulta histórica.

## Tecnologías

* Frontend: HTML, CSS, JavaScript, bootstrap


## Equipo

Proyecto desarrollado por un equipo de 4 integrantes bajo la metodología **Scrum**.
